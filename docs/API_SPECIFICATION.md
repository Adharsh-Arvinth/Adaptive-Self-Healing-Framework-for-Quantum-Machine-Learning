# API Specification: REST & WebSocket Contracts

> **NOTICE:** All JSON payloads, response structures, and episode records in this document are **ILLUSTRATIVE SCHEMA SPECIFICATIONS ONLY**. They define API wire contracts and must **NEVER** be interpreted as actual experimental measurements or verified benchmark outcomes. Actual experimental data is strictly recorded in `docs/EXPERIMENT_LOG.md` and generated by executing the backend pipeline.

**Document:** Backend Service Interface Contracts  
**Framework:** FastAPI 0.162+ • Pydantic v2 • WebSockets  
**Date:** March 2026

---

## 1. REST Endpoints

### 1.1 Model & Experiment Control
- **`POST /api/v1/experiment/start`**
  - *Request Body:*
    ```json
    {
      "dataset_name": "moons",
      "n_qubits": 2,
      "n_layers": 2,
      "feature_map": "angle",
      "ansatz_type": "basic_entangling",
      "optimizer_name": "adam",
      "learning_rate": 0.05,
      "total_epochs": 40,
      "random_seed": 42,
      "repair_policy": "contextual_ts"
    }
    ```
  - *Response (200 OK):*
    ```json
    {
      "experiment_id": "exp_20260302_001",
      "status": "INITIALIZED",
      "timestamp": "2026-03-02T14:30:00Z"
    }
    ```

- **`POST /api/v1/experiment/stop`**
  - *Query Param:* `experiment_id: str`
  - *Response (200 OK):* `{"status": "STOPPED"}`

- **`POST /api/v1/experiment/inject-failure`**
  - *Request Body:*
    ```json
    {
      "experiment_id": "exp_20260302_001",
      "failure_type": "barren_plateau",
      "severity": 1.0
    }
    ```
  - *Response (200 OK):*
    ```json
    {
      "status": "FAILURE_INJECTED",
      "failure_type": "barren_plateau",
      "epoch": 15
    }
    ```

  - *Client sends:* `{"action": "subscribe"}`
